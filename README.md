# Exercícios de Fundamentos de Programação em Python

Este repositório reúne minhas resoluções de exercícios de fundamentos de programação, adaptados para a linguagem Python.

Os exercícios têm como base de estudo o livro *Fundamentos da Programação de Computadores: algoritmos, PASCAL, C/C++ (padrão ANSI) e JAVA*, de Ana Fernanda Gomes Ascencio e Edilene Aparecida Veneruchi de Campos.

O objetivo deste repositório é registrar minha evolução prática em lógica de programação, estruturas condicionais, estruturas de repetição, listas, funções e outros conceitos fundamentais, utilizando Python como linguagem principal.

## Objetivo do projeto

Este projeto tem fins exclusivamente educacionais.

A proposta é:

- praticar lógica de programação;
- adaptar algoritmos tradicionais para Python;
- organizar os exercícios por conteúdo;
- acompanhar minha evolução nos estudos;
- manter um histórico de versões usando Git e GitHub.

## Organização das pastas

O repositório está organizado por tópicos de estudo:

- `01-estrutura-sequencial`: exercícios com entrada, processamento e saída de dados;
- `02-estrutura-condicional`: exercícios com `if`, `elif` e `else`;
- `03-estrutura-repeticao`: exercícios com estruturas de repetição;
- `04-vetores_ou_listas`: exercícios com listas, índices, percursos e cálculos com coleções de dados.

## Tecnologias utilizadas

## Observação sobre os exercícios

Os enunciados originais pertencem à obra utilizada como referência. Neste repositório, os exercícios são estudados e implementados em Python como prática pessoal de programação.

Sempre que necessário, os algoritmos são adaptados para refletir a sintaxe, os recursos e as boas práticas da linguagem Python.
